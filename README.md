# Telegram Inviter Bot

Этот бот позволяет автоматизировать насильное добавление пользователей в Telegram-группы и каналы. Он анализирует активность пользователей в исходных чатах, собирает их и приглашает в указанную целевую группу.

## ▌Особенности

•   **Автоматизированное приглашение:**  Собирает активных пользователей из одного чата и приглашает их в другой.
•   **Поддержка нескольких аккаунтов:** Позволяет использовать несколько аккаунтов Telegram для увеличения производительности и избежания ограничений.
•   **Авторизация через ключ:**  Ограничивает доступ к боту с помощью ключей авторизации, обеспечивая безопасность.
•   **Параллельная обработка задач:**  Поддерживает одновременное выполнение нескольких задач для ускорения процесса.
•   **Управление аккаунтами:** Добавление и список аккаунтов Telegram.
•   **Статистика задач:**  Отображает текущий статус задач, находящихся в обработке.
•   **Реферальная программа:** Возможность заработка на приглашениях новых пользователей.
•   **Логирование:** Подробное логирование всех действий бота для отладки и мониторинга.

## ▌Требования

•   Python 3.9+
•   `aiogram`
•   `telethon`
•   Переменные окружения:
    •   `BOT_TOKEN` - Токен вашего Telegram-бота.
    •   `API_ID` -  API ID из [my.telegram.org](https://my.telegram.org/apps).
    •   `API_HASH` - API Hash из [my.telegram.org](https://my.telegram.org/apps).
    •   `ADMIN_USER_IDS` - Список ID пользователей-администраторов бота, разделенных запятыми.
    •   `MAX_CONCURRENT_TASKS` - (Необязательно) Максимальное количество параллельных задач (по умолчанию: 10).
    •   `SESSIONS_DIR` - (Необязательно) Директория для хранения сессий Telegram (по умолчанию: "sessions").
    •   `DATA_DIR` - (Необязательно) Директория для хранения данных (по умолчанию: "data").
    •   `AUTH_FILE` - (Необязательно) Файл для хранения данных авторизации (по умолчанию: `data/auth.json`).

## ▌Использование

1. Запустите бота:

  
```bash
  python main.py
```

2. Добавьте аккаунты Telegram с помощью команды /add_account. Следуйте инструкциям бота.
3. Начните сбор пользователей с помощью команды /start_scraping. Следуйте инструкциям бота для указания исходного и целевого чатов.
4. Просматривайте статистику задач с помощью команды /task_stats.
5. Используйте команду /help для получения справки.

## ▌Команды бота

-•  /start - Начало работы с ботом, отображает доступные команды.
-•  /help - Отображает руководство по использованию бота.
-•  /ref - Информация о реферальной программе.
-•  /add_account - Добавить аккаунт Telegram. Боту понадобится номер телефона аккаунта и код подтверждения из Telegram.
-•  /list_accounts - Список доступных аккаунтов.
-•  /start_scraping - Начать сбор пользователей и приглашение в целевую группу.
-•  /task_stats - Отображает статистику активных задач.
-•  /genkey - (Только для администраторов) Генерирует ключ доступа для новых пользователей бота.

## ▌Конфигурация

Все настройки бота хранятся в классе Config в файле bot.py. Вы можете изменить эти настройки в коде.

-•  BOT_TOKEN: Токен Telegram-бота (обязательно).
-•  API_ID: API ID из my.telegram.org (https://my.telegram.org/apps) (обязательно).
-•  API_HASH: API Hash из my.telegram.org (https://my.telegram.org/apps) (обязательно).
-•  ADMIN_USER_IDS: Список ID администраторов (обязательно).
-•  MAX_CONCURRENT_TASKS: Максимальное количество одновременных задач (по умолчанию: 10).
-•  SESSIONS_DIR: Директория для хранения сессий Telegram (по умолчанию: "sessions").
-•  DATA_DIR: Директория для хранения данных (по умолчанию: "data").
-•  AUTH_FILE: Файл для хранения данных авторизации (по умолчанию: data/auth.json).

## ▌Безопасность

-•  Ваши сессии Telegram хранятся локально и не передаются третьим лицам.
-•  Бот использует ключи авторизации для ограничения доступа к функциям.
-•  Ваши другие сессии Telegram останутся активными.
