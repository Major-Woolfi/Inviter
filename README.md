# Telegram Inviter Bot
<br>
Этот бот позволяет автоматизировать насильное добавление пользователей в Telegram-группы и каналы. Он анализирует активность пользователей в исходных чатах, собирает их и приглашает в указанную целевую группу.
<br>

## ▌Особенности
<br>

•   **Автоматизированное приглашение:**  Собирает активных пользователей из одного чата и приглашает их в другой.<br>
•   **Поддержка нескольких аккаунтов:** Позволяет использовать несколько аккаунтов Telegram для увеличения производительности и избежания ограничений.<br>
•   **Авторизация через ключ:**  Ограничивает доступ к боту с помощью ключей авторизации, обеспечивая безопасность.<br>
•   **Параллельная обработка задач:**  Поддерживает одновременное выполнение нескольких задач для ускорения процесса.<br>
•   **Управление аккаунтами:** Добавление и список аккаунтов Telegram.<br>
•   **Статистика задач:**  Отображает текущий статус задач, находящихся в обработке.<br>
•   **Реферальная программа:** Возможность заработка на приглашениях новых пользователей.<br>
•   **Логирование:** Подробное логирование всех действий бота для отладки и мониторинга.<br>

<br>

## ▌Требования
<br>

•   Python 3.9+<br>
•   `aiogram`<br>
•   `telethon`<br>
•   Переменные окружения:<br>
    •   `BOT_TOKEN` - Токен вашего Telegram-бота.<br>
    •   `API_ID` -  API ID из [my.telegram.org](https://my.telegram.org/apps).<br>
    •   `API_HASH` - API Hash из [my.telegram.org](https://my.telegram.org/apps).<br>
    •   `ADMIN_USER_IDS` - Список ID пользователей-администраторов бота, разделенных запятыми.<br>
    •   `MAX_CONCURRENT_TASKS` - (Необязательно) Максимальное количество параллельных задач (по умолчанию: 10).<br>
    •   `SESSIONS_DIR` - (Необязательно) Директория для хранения сессий Telegram (по умолчанию: "sessions").<br>
    •   `DATA_DIR` - (Необязательно) Директория для хранения данных (по умолчанию: "data").<br>
    •   `AUTH_FILE` - (Необязательно) Файл для хранения данных авторизации (по умолчанию: `data/auth.json`).<br>

<br>

## ▌Использование
<br>
1. Запустите бота:
<br>
  
```bash
  python main.py
```
<br>

2. Добавьте аккаунты Telegram с помощью команды /add_account. Следуйте инструкциям бота.<br>
3. Начните сбор пользователей с помощью команды /start_scraping. Следуйте инструкциям бота для указания исходного и целевого чатов.<br>
4. Просматривайте статистику задач с помощью команды /task_stats.<br>
5. Используйте команду /help для получения справки.<br>

<br>

## ▌Команды бота
<br>

•  /start - Начало работы с ботом, отображает доступные команды.<br>
•  /help - Отображает руководство по использованию бота.<br>
•  /ref - Информация о реферальной программе.<br>
•  /add_account - Добавить аккаунт Telegram. Боту понадобится номер телефона аккаунта и код подтверждения из Telegram.<br>
•  /list_accounts - Список доступных аккаунтов.<br>
•  /start_scraping - Начать сбор пользователей и приглашение в целевую группу.<br>
•  /task_stats - Отображает статистику активных задач.<br>
•  /genkey - (Только для администраторов) Генерирует ключ доступа для новых пользователей бота.<br>

<br>

## ▌Конфигурация
<br>

Все настройки бота хранятся в классе Config в файле bot.py. Вы можете изменить эти настройки в коде.<br>

<br>

•  BOT_TOKEN: Токен Telegram-бота (обязательно).<br>
•  API_ID: API ID из my.telegram.org (https://my.telegram.org/apps) (обязательно).<br>
•  API_HASH: API Hash из my.telegram.org (https://my.telegram.org/apps) (обязательно).<br>
•  ADMIN_USER_IDS: Список ID администраторов (обязательно).<br>
•  MAX_CONCURRENT_TASKS: Максимальное количество одновременных задач (по умолчанию: 10).<br>
•  SESSIONS_DIR: Директория для хранения сессий Telegram (по умолчанию: "sessions").<br>
•  DATA_DIR: Директория для хранения данных (по умолчанию: "data").<br>
•  AUTH_FILE: Файл для хранения данных авторизации (по умолчанию: data/auth.json).<br>

<br>

## ▌Безопасность
<br>

•  Ваши сессии Telegram хранятся локально и не передаются третьим лицам.<br>
•  Бот использует ключи авторизации для ограничения доступа к функциям.<br>
•  Ваши другие сессии Telegram останутся активными.<br>
