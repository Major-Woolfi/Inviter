# Inviter Bot — Telegram-бот для инвайтов и рассылок

**Inviter** — монолитный Telegram-бот для массового приглашения участников и рассылки сообщений с продвинутыми анти-блокировочными механизмами.

Это не просто бот — это полноценная платформа для работы с Telegram-чатами через несколько аккаунтов, с автоматической обработкой FloodWait, ротацией сессий и детальным мониторингом задач.

[![Status](https://img.shields.io/badge/Status-Active-brightgreen.svg)]()

## 🎯 Цели проекта

- Предоставить надёжный инструмент для массовых инвайтов в Telegram
- Реализовать анти-блокировочную систему для защиты аккаунтов
- Создать монолитную архитектуру для простого деплоя и отладки

## 📋 Быстрый старт

### Локальный запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Настройка
cp .env.example .env
# Отредактируйте .env

# Запуск
python main.py
```

### Docker

```bash
# Сборка и запуск
docker build -t inviter_bot .
docker run -d --name inviter_bot --restart always -v "$(pwd)":/app inviter_bot
```

### Деплой на сервер

```bash
cd Inviter/
./deploy_bot.sh
```

## 🛡️ Анти-блокировочные механизмы

- 🛡️ Случайные задержки между действиями (40–70 сек)
- 🛡️ Умная обработка FloodWait с увеличенным временем ожидания (×1.5)
- 🛡️ Ротация аккаунтов (round-robin балансировка)
- 🛡️ Автоматический retry при ошибках (3 попытки)
- 🛡️ Кэширование участников через SQLite
- 🛡️ Фильтрация ботов и проверка membership
- 🛡️ Фоновый health-check аккаунтов

## 📌 Ограничения и примечания

- Используйте несколько аккаунтов для распределения нагрузки
- Не превышайте 100 инвайтов в час на один аккаунт
- FSM хранится в памяти — состояния сбрасываются при перезапуске
- Архитектура монолитная (`main.py`) для простоты деплоя
