# Сводка изменений Inviter v2.0

## ✅ Реализованный функционал

### 1. Языковая система (langs/)
- `langs/ru.json` — полный русский перевод (130+ ключей)
- `langs/en.json` — английский fallback
- Функции `_load_language_file()`, `_resolve_key()`, `translate()`
- Кэш языков `_LANG_CACHE` (макс 100 записей)
- Автоматическая подгрузка ru/en при старте

### 2. Новая БД чатов (ChatDB)
- Таблица `collected_chats` с полями: chat_id, chat_name, chat_url, chat_type, user_count, can_write, verified, last_check, status
- Методы: `add_chat()`, `remove_chat()`, `update_chat_status()`, `get_all_chats()`, `get_chat()`, `get_total_users()`, `get_active_chats_count()`, `clear_db()`
- Индексы по status и can_write
- PRAGMA WAL mode для производительности

### 3. Режим червя 🐛
- **Парсинг ссылок:** regex-паттерны для `https://t.me/`, `t.me/`, `@username`
- **Функция `extract_telegram_links()`** — извлекает все t.me ссылки из текста
- **Функция `validate_and_test_chat()`** — валидация чатов с тестом писания
- **Функция `check_and_clean_banned_chats()`** — проверка забаненных чатов
- Управление: `/worm_mode`, `/stop_worm`
- Статистика в реальном времени

### 4. Добавление чатов в БД
- Поддержка текста (пробел/запятая/новая строка) и файлов (.txt)
- Уникализация ссылок через parse_link_to_identifier
- Лимит 50 чатов за одну партию
- Детальный отчёт о результатах

### 5. Обновление БД чатов
- Проход по всем чатам в БД
- Проверка через telethon (get_entity)
- Проверка can_send_messages через aiogram
- Если бот забанен — удаление из БД
- Отчёт: проверено, добавлено, удалено, ошибок

### 6. МНОЖЕСТВЕННЫЕ ТЕКСТЫ ДЛЯ РАССЫЛКИ 🆕
- **Новый функционал:** каждая рассылка теперь поддерживает несколько текстов
- Пользователь отправляет тексты по одному
- Каждый текст сохраняется в список
- Тексты циклически轮换ются при отправке
- Интеграция с `bulk_mailing_task`
- UI: "➕ Добавить ещё текст", "✅ Готово, продолжить"

### 7. РАССЫЛКА/ПАРСИНГ ПО ЧАТАМ ИЗ БД 🆕
- **Новый функционал:** использование чатов из БД для рассылки и парсинга
- Выбор источника: ручной ввод или БД
- Для рассылки: `bulkmail_source:db`
- Для парсинга: `scraping_source:db`
- Новая функция `db_scrape_and_invite_task()` — парсинг из всех чатов БД
- Статистика: количество обработанных чатов, собранных пользователей

### 9. Перевод всех текстов
Все тексты переведены на `translate()`:
- Авторизация (auth_required, auth_success, auth_invalid)
- Добавление аккаунта (phone, safety_notice, code, password, account_added)
- Генерация ключа (genkey_title, genkey_success)
- Сброс кэша (clear_cache_confirm, cache_cleared)
- Помощь и рефералка (help_text, ref_text)
- Список аккаунтов (no_accounts, accounts_list)
- Ошибки и статусы

## 🆕 Новые возможности v2.0

### Множественные тексты для рассылки
- Пользователь может отправить неограниченное количество текстов
- Каждый текст отправляется по очереди циклически
- Пример: 3 текста × 100 отправок = 100 циклов

### Рассылка из БД
- Выбор источника чатов: ручной ввод или БД
- Автоматическое использование всех чатов из ChatDB
- Отчёт по количеству использованных чатов

### Парсинг из БД
- Сбор пользователей из всех чатов в БД
- Каждый чат обрабатывается отдельно
- Статистика по обработанным чатам и собранным пользователям
